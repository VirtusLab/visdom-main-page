# Brand assets

Rendered from `assets/logos/` in the `visdom-materials` repository, which is the source of truth.
They live here because they have to be reachable over HTTP: the GitBook documentation site at
visdom.gitbook.io/docs takes its logo and favicon as URLs.

Naming says which background the asset is *for*, not what colour it is:

| File | Ink | Use on |
| --- | --- | --- |
| `visdom-logo-on-light.*` | `#0c0a09` | light backgrounds |
| `visdom-logo-on-dark.*` | `#f5f5f4` | dark backgrounds |
| `visdom-mark-ink.png` | `#0c0a09` | favicon, light |
| `visdom-mark-paper.png` | `#f5f5f4` | favicon, dark |
